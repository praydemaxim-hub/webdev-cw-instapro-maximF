# Instapro

MVP социальной сети для обмена фотографиями.

## Реализованная функциональность

### Для всех пользователей
Общая лента постов для всех пользователей.
Страница постов конкретного пользователя открывается по клику на имя пользователя.
Авторизация и регистрация.
Пользователь остаётся авторизованным после перезагрузки страницы.

### Для авторизованных пользователей
Добавление постов — можно загрузить фото и написать описание.
Можно ставить и снимать лайки без перезагрузки страницы.
Просмотр своих и чужих постов — доступ ко всем пользователям.
